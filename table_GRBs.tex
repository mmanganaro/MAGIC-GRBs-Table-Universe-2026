
This table reports observational results published from the MAGIC collaboration up to now (many other observations were performed after the last GRB mentioned in this table, but here we have the ones published so far. The tablereports the name of the GRBs; the redshift (in many cases still unknown); the $T_{delay}$ with respect to the start of the trigger T$_{0}$, meaning the time at which MAGIC telescopes started to observe the source; the duration of the MAGIC observations; the energy range E$_{range}[GeV]$ of the MAGIC analysis; the maximum flux reached; the Z$_{d}[deg]$ of the MAGIC observations; the type of GRB (Long or short); if it was detected or, in case of non detection, if there are ULs; and the reference for the published data in which all the details on the respective analysis can be found. We recommend to use the references before to use the data: in many cases the data we report are taken under different assumptions (for instance, an assumed spectrum or a specific redshift limit), so it is better to go to the original article and check the analysis details.
