## Column definitions and notes

- **z:** redshift; Unknown denotes an unreported redshift in the source table.
- **Delay:** time between the trigger T0 and the start of MAGIC observations.
- **Obs. time:** observation duration as reported in the source table.
- **Energy range:** energy interval used in the MAGIC analysis, in GeV. `>140` is a lower threshold, not a finite interval.
- **Fmax:** maximum flux or reported flux upper limit, in erg cm⁻² s⁻¹, depending on the detection status. Values may refer to different analysis intervals and assumptions.
- **Zenith angle:** range of observing zenith angles, in degrees.
- **Detection:** Detected, hint of detection, UL (upper limit), or ULs (upper limits), as in the original table.
- `*` marks values awaiting publication in Suda et al. (2026), as indicated in the source table.

The ASCII file uses tabs as delimiters, `NA` for unavailable values, and scientific notation (e.g. `5e-8`). `energy_kind` distinguishes a finite range, a strict lower threshold (`gt`), and pending values. Multiple reference IDs are separated by semicolons and match the BibTeX keys. GRB identifiers should be read as strings to retain leading zeros.

**Important:** The values are reproduced from the supplied compilation. Consult the original publications before using them for quantitative comparisons, as analysis assumptions (e.g. spectrum and redshift) may differ. No unit conversions or scientific corrections have been applied.
